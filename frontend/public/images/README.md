# Images Folder

Place your images here:

## Required Images:

1. **logo.png** or **logo.svg** - Your app logo (for sidebar and header)
2. **dashboard-bg.png** or **dashboard-bg.jpg** - Dashboard background image
3. **hero-bg.png** - Optional hero section background

## Usage:

In React components, reference images as:
```jsx
<img src="/images/logo.png" alt="Logo" />
```

Or as CSS background:
```css
background-image: url('/images/dashboard-bg.png');
```

## Recommended Sizes:

- **Logo**: 120x120px (PNG with transparent background)
- **Dashboard Background**: 1920x1080px (optimized JPG/PNG)
- **Hero Background**: 1600x900px
